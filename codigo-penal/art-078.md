CAPITULO III
PUNIBILIDAD EN CASO DE ERROR VENCIBLE
Artículo 78.- Aplicación de pena en caso de error vencible.- Cuando los errores a que se refiere la fracción X del artículo 23 de este Código sean vencibles, se impondrá al sujeto que se encuentre en dicha situación hasta una mitad del máximo de las penas previstas para el delito de que se trata.
